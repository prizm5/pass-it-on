# Project Requirements

Design a platform to enable free exchange of kids clothing and other kid items with in daycare or between daycares. Users would self register and be able to post items with pictures for exchange.

## Basic Facts

* Works on phones primarily but also can be used on a desktop browser.
* Minimal information kept about the participants.
* Need users to create a user profile
* We only store registration information. No payment information. Users can add third party payment information on their profile. 
* Users can use a social login of choice. 

## Technical Notes
